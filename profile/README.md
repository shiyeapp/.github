# 时页

时页是一款本地优先的日记与回忆整理应用。用文字、照片和当下的状态记下生活，在时间线找回原文。配置自己的 AI 服务后，可以从记录中选材生成篇章，核对来源，再保存想留下的内容。

无需注册时页账号。记录、回看和备份导出可以在关闭 AI 时使用。
